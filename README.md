# Doors Hospitality Design

A responsive portfolio concept for Doors, a hospitality design studio focused on serviced apartments and memorable guest stays.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

The project is ready to import into Vercel as a standard Next.js application.

## Routes

- `/` — design direction selector
- `/atelier` — warm editorial direction
- `/monolith` — bold architectural direction
- `/canvas` — artistic playful direction

Contact details are presentation placeholders and should be replaced before the final client launch.
